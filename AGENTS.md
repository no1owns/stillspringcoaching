# Still Spring Coaching | Website development

## Project and references

- Still Spring Coaching is Mia Feldbaum’s practice for adults navigating change, neurodivergence, disability, and everyday challenges, including people supporting loved ones.
- Work in the existing site at `no1owns/stillspringcoaching`. Make targeted changes to the current pages, shared styles, and components.

- [GitHub Pages development site](https://no1owns.github.io/stillspringcoaching/index.html)

## Design and copy

- Use the current site as the implementation baseline. For each change, use the specific Figma frame, asset, or copy supplied in the approved batch brief. If sources conflict, follow the most recent explicit approval for that element.
- Preserve Bright Clarity: an editorial, approachable, nature-informed direction with teal and cream, clear typography, and intentional spacing. Use Atkinson Hyperlegible for body copy and reuse the site’s current tokens and components.
- Preserve the homepage hero composition and readable text treatment. Apply hero imagery, display type, logo, and portrait updates only when the batch names the approved asset or decision.
- Use approved copy. Keep Mia’s voice warm, direct, and practical. Avoid unverified credentials, testimonials, outcomes, rates, offers, or scheduling details.

## Implementation and review

1. Read the batch brief, inspect the current files and deployment configuration, and start a feature branch from the latest `main`.
2. Make the scoped changes. Reuse existing code and assets. Keep current page URLs, working navigation, and GitHub Pages deployment intact.
3. Use the repository’s existing preview and test commands if documented. Review affected pages on desktop, tablet, and mobile. Check keyboard navigation, visible focus, contrast, heading structure, links, and any changed interactions. A form may report success only after a real submission.
4. Push the feature branch and open a pull request against `main`. Include the changes, checks performed, and any outstanding decisions or gaps. Merge and verify the GitHub Pages deployment when the batch authorizes it.
5. Get explicit approval before connecting the custom domain or activating a new booking or payment flow.

Use the batch brief for current Figma frames, copy revisions, asset filenames, and QA findings. Keep exploratory designs and private client materials out of the public repository.
